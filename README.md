# VFX Template Reference

Reference Luau code for combat and visual-effects systems in Roblox. This
repository is intended as material for developers and AI agents to consult and
adapt; it is not a ready-to-publish Roblox experience.

## Source layout

- `src/client/` contains client-side combat input, animations, and visual
  effects.
- `src/server/` contains combat handling, hit validation, delivery logic, and
  development tools.
- `src/shared/` contains shared combat configuration, types, utilities, and
  modules.

Use the modules as examples and adapt their dependencies, asset references, and
project paths to the target experience.
